## 已验证

最终全量检查：`go build ./...`、`go vet ./...`、`CODING_TEST_BROWSER=… go test ./...`、`git diff --check` 均通过。最终全量 Go 测试中 server 为 26.153 秒，web 沿用此前 213.419 秒通过的缓存结果；最近修改集中于服务端。

- 既有 `go test ./...`：设置 `CODING_TEST_BROWSER` 为本机 Chrome 后通过，包含服务器与真实浏览器套件。初始基线未显式指定 Chrome 路径时浏览器要求失败；这是环境配置问题，指定路径后复测通过。
- GitHub 既有触发验收继续覆盖写权限、Bot 过滤、fork、预算/频率、工作流审批、一次推送、取消/失败/无改动与中断恢复。无连接时现在安静忽略；回复由异步发件箱处理，已有断言按新契约调整。
- Memory 和真实临时 Postgres 的 `-race` 并发探针：20 次并发入队、12 次并发领取；去重、跨租户隔离、预算预留、过期 fencing、连接快照、持久私有负载、释放租约不覆盖并发确认、告警窗口去重、五次失败死信、GitHub 人工重放先核对、未知状态禁止重发。
- 跨进程元数据探针：两个 Store 实例和两个独立进程并发追加，项目/会话/任务各 60 条无丢失；持锁进程被杀后自动释放。Windows/Linux 交叉编译与既有会话回归通过，范围见 `docs/ui/entry-metadata-locking.md`。
- 五组服务端端到端探针（真实 handler、替身 Runtime/GitHub）：单次定时任务、重建服务不重复工作区/Task、停用后已有任务继续、冻结配置与出口、防重复并发、多条告警的准入预算，以及通知会话深链。
- Webhook HTTP 验收：没有密钥时 body 读取次数为 0；错误 token、非法字段/cron/限额拒绝；跨租户读写不可见；列表不含密钥；无 SMTP 时可存停用邮件连接但不可启用邮件出口；DMARC/已验证发件人/自动回复过滤。
